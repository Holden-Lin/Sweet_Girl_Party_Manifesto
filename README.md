# 甜妹党宣言

**简体中文** | [English](README.en.md)

本仓库现在区分了两类内容：`README` 用来解释项目的核心命题、理论框架与阅读入口；完整正文则保存在 `MANIFESTO` 文件中。这里的核心判断是：在一个注意力被切碎、制度中介被削弱、社会持续极化的时代，`甜` 比 `善` 更具传播性、执行性与去极化能力。

## 为什么是“甜”，不是“善”

- `甜` 是前认知的，`善` 是后判断的。善往往需要稳定的伦理框架、认知带宽与反思能力；甜则可以通过表情、语调、姿态和微小善意被直接感受到。
- `甜` 借助情绪感染扩散，`善` 往往依赖制度中介。当前的法律、公论、教育与共同注意力都在被削弱，而甜可以在人与人之间低成本传播。
- `甜` 更难被武器化。善容易在善/恶二元中滑向审判与惩罚；甜作为一种审美-情感品质，不天然生成“有罪/无罪”的结构。
- `甜` 的参与门槛更低。一句温柔的话、一次耐心回应、一杯水、一个真诚的微笑，都足以构成可复制的社会实践。
- `甜` 更适合去极化。它不是先分类再动员，而是先修复情感连接，再为合作、正义与长期行动提供基础设施。

## 甜作为熵减策略

这个项目把当下的注意力碎片化、情绪极化和社会原子化理解为一种社会熵增。传统意义上的“善”通常试图通过更高层级的道德秩序来纠偏，但这些秩序本身也在失效。`甜` 的策略不是自上而下强加秩序，而是在局部互动中持续注入负熵：增加信任、降低敌意、恢复联结，让秩序以去中心化的方式重新涌现。

换句话说，甜不是宏大口号，而是一种微观但高频的社会技术。

## 对常见质疑的回应

- `甜` 不是正义的替代品。它修复的是正义得以运作的社会地基：共情、信任、最基本的人际温度。
- `甜` 不是隐蔽的情感操控。操控是单向的、隐蔽的、服务于操控者利益的；甜强调的是双向、透明、分布式的关系实践。
- `甜` 不是软弱。它并不取消对系统性暴力的反抗，而是反对在全面冷漠和全面极化的土壤上空谈更高道德。
